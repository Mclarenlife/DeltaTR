# DeltaTR

精简的本地赛车 Team Radio。读取 Assetto Corsa Competizione、Le Mans Ultimate 或 iRacing 遥测，按住 F8 直接询问车辆或赛场状况，由工程师语音回答。

**当前版本：0.13.4。** KS Pro 支持保留 Pit House 的智能仪表切换：共用讲话键，短按切换 DeltaTR / 原比赛仪表，长按 0.5 秒开始讲话、松开发送；赛事提醒和自动化播报临时弹出，结束后返回。手动打开的画面保持显示。使用独立文字字段，支持旧桥接升级与双文件备份恢复。升级时点击「安装 / 升级桥接」并重启 Pit House；保留已上传的 `DeltaTR KS Pro Wave Radio` 仪表，先在 Pit House 选择比赛仪表，再开启方向盘屏显。详见 [KS Pro 使用说明](docs/MOZA_KS_PRO.md)。

## 开始使用

- 启动后先在左侧栏顶部选择游戏。选择后软件自动等待对应游戏并读取遥测。进入座舱后，可在无线电页面查看适用问法。
- 演示：选择游戏后点击「启动演示」。用 `Start-Demo.cmd` 启动时，选择游戏即进入该游戏的演示。切换游戏会停止当前采集和讲话、关闭屏显并清空对话；自定义词库按游戏保存。
- ACC 支持本车共享内存和赛事广播。LMU 使用原生 `LMU_Data` 接口读取玩家车辆。iRacing 使用本机 SDK 实时变量；四轮冷胎压设定与上次测量的轮胎数据单独标注。
- 已构建程序：`artifacts/releases/0.13.4/app/DeltaTR.App.exe`。发布目录需要整体保留。
- 在「设置 → 语音与无线电」点击「重新绑定」，按一次键盘键或方向盘上的实体按钮，显示设备名称和按钮后即可使用。Esc 取消。默认按住 **F8** 讲话，松开发送；也可按住无线电页面的按钮。单次最多 15 秒。
- 三款游戏都可试问「还剩多少油」「排名」「现在车速多少」。轮胎与其他可用问法见当前游戏的「自定义词库」。
- 新的讲话会打断播报；「停止播报」立即停止声音。输入文字也可得到语音回答。

需要 Windows x64 和 .NET 10 Desktop Runtime。在「设置 → 语音与无线电 → 识别引擎」可切换 SenseVoice、Windows 识别和 Zipformer，选择立即保存。新安装默认 SenseVoice，旧配置保留已有引擎选择。完整发布目录自带 SenseVoice 中文整句识别模型与 Zipformer 中英双语 CPU 模型；Windows 识别使用系统中文组件。三者共用自定义问法、唤醒词和麦克风设置。SenseVoice 使用应用层词库匹配及同音纠错，不宣称支持原生热词解码。播报使用系统的中文声音。

连接 ACC 时，在同一台电脑和同一 Windows 会话中启动游戏及 DeltaTR，载入练习赛后点击「驾驶」。软件会自动读取共享遥测。在演示模式下点击「连接 ACC」切换。顶栏显示驾驶、暂停或重播状态，设置的数据源区域显示详细原因。暂停时请返回座舱并解除暂停。设置中的「显示与播报单位」可以在公制（°C、km/h、L）与英制（°F、mph、英制加仑）之间切换。胎压在两种模式下均使用 ACC 的 psi。

在「设置 → 语音与无线电」选择麦克风和扬声器，点击「测试麦克风」观察右侧实时电平。可分别开启语音增强和麦克风降噪，两项默认关闭。测试电平和讲话阈值使用处理后的声音。白线是输入阈值，低于阈值的输入显示为灰色，达到阈值时显示为绿色。拖动滑块立即更新判断，保存后下次启动继续使用。再按住绑定的键或按钮试说“当前轮胎温度多少”。默认输入峰值阈值为 2%。Windows 识别的置信度阈值默认为 35%，SenseVoice 和 Zipformer 按词库匹配或句首唤醒词分流，不套用 Windows 置信度阈值。松开后可看到峰值、时长和识别结果。可以依提示分别调整两个滑块。

使用 AI 时，填写兼容 Chat Completions 的服务地址、模型、密钥和唤醒词，点击「保存设置」。本机免认证服务可留空密钥。普通问句如“轮胎温度多少”直接查遥测。“工程师，我应该第几圈进站”使用配置的 API。每个 AI 问句都要以唤醒词开头，同一驾驶会话最多附带最近三轮 AI 对话。API 接收文本和当时有效的遥测。密钥由 Windows 当前用户加密后保存在本机设置中。

在「自定义词库」左侧选遥测项目，右侧每行填写一种问法，点击「保存词库」。例如为气温添加“报告气温”，下一次按住讲话键 就可使用。文字查询使用相同的词库。语音先匹配已保存的完整问法，再尝试纠正“台温／胎温”等术语误写。只有唯一匹配才会查询；识别记录展示原文与采用的问法。AI 唤醒词沿用句首匹配。

在「设置 → 赛事主动提醒」按游戏配置黄旗、排名、处罚，以及蓝旗、黄旗解除、进出维修区、每圈和比赛开始/结束提醒。黄旗、排名和处罚默认开启，其他类别按需开启。排名变化在新鲜数据中确认约半秒后播报，短暂缺失读数会保留前一次有效名次，讲话期间的提醒最多排队 30 秒。确认是哪辆车换位后，会附带对方当前速度与你的差值。ACC 需要连接广播获得对手数据，LMU 使用单车计时速度，iRacing 使用车辆圈进度和赛道长度估算，并明确播报“估计”。

「策略组」按游戏保存回复长度、稳健/均衡/进取倾向和自定义对话偏好，统一用于 AI 工程师对话。进站分析、换胎分析、圈速保持分析可分别展示，点击“开始分析”后通过已配置的 API 获取建议，在卡片和无线电显示结果。默认简短回复、均衡策略，并展示三个分析模块。圈速分析使用本次会话最近最多六个采样圈，过滤观察到的进站、加油或无效圈，缺少数据时说明所需依据。

「自动化」支持按当前游戏新建、编辑、停用和删除规则。可直接使用“比赛开始 → 排名”和“每两分钟 → 排名、头车秒差、前车秒差”模板，添加动作并上下调整顺序。模板需保存后生效。间隔输入单位为秒，120 秒等于两分钟，范围 10–3600 秒。有效驾驶时间累计，暂停、断线时暂停计时。事件触发需要先观察到事件前的状态，比赛中途连接不会补播开赛消息。

演示模式约 4 秒开始比赛、15 秒出现黄旗、30 秒提升排名、45 秒收到处罚、70 秒被超车降名次。可用于试听广播和自动化。

LMU 和 iRacing 的「赛事播报」随游戏遥测连接，可问“前车是谁”“比赛排名表”“现在是什么旗”，无需单独设置广播端口。LMU 可问“虚拟能量还剩多少”；iRacing 会按会话公布的变量与车手资料更新词库，支持按 SDK 变量名搜索和配置问法。完整范围见 `docs/GAME_TELEMETRY.md`。

在「设置 → ACC 赛事广播」查看第二条数据源。若端口关闭，点击「启用游戏广播端口」并重启 ACC。DeltaTR 使用游戏已有的本机连接口令，自动注册并在超时后重试。可问“前车是谁”“分段排名”“前车上一圈多少”。“第1名的详细赛况”可以查看该排名车辆的报名、驾驶和圈速信息。广播断开时仍可查询本车数据。自定义词库支持按中文名称、分组或字段名搜索。

在「屏显」中分别调整冰晶形象和文字气泡的大小、位置和各层不透明度。断开时气泡显示“未连接”。连接游戏或演示后，冰晶始终可见，待命时只收起气泡。输入和回答时显示气泡，回复约八秒后收起。无线电页面的本地查询结果随遥测刷新，语音在提问时播报一次。拖动形象可移动位置。

## 语音与数据边界

NAudio 采集 16 kHz 单声道 PCM。Zipformer 在按住讲话键期间流式解码，首句会加载模型，同一引擎下后续讲话复用模型。SenseVoice 和 Windows 引擎在松键后识别整句。SenseVoice 首次加载模型后保持复用，切换到其他引擎时释放；使用两个 CPU 推理线程。三者都在松键并通过音量阈值后提交问题。本地识别不上传或保存音频。

支持有限的中文问句，详见 [语音说明](docs/VOICE_COMMANDS.md)。没有听清、多个问题或不支持的问题不会进入数值回答。识别置信度门槛是保守启发式，并不代表识别准确率。

已只读连接真实 ACC 暂停会话。共享内存标识 1.9 和项目测试布局 1.8.12 的明确字段在对应数据页持续更新后可用于问答。车辆暂停、数据失效或超过两秒时停止播报。内置 ACC 读取规则采用 °C、psi、km/h 与 L，倒计时根据实际递减速度判别秒和毫秒。若倒计时未运行，则等待有效读数。已加载且匹配的旧核验配置仍可确定燃油质量或体积等原始单位。

```text
    Views/                        四个产品页面、内嵌字段检查器
    ViewModels/                   遥测界面与语音交互状态
    Input/                        全局 F8 按住讲话
    Themes/                       共用样式
    Diagnostics/                  界面与语音集成检查
  DeltaTR.Voice/                   麦克风采集、离线 ASR、TTS、识别结果门禁
  DeltaTR.Engineer/                问句意图、基于新鲜遥测的回答
  DeltaTR.Core/                    快照、质量、校准证据模型
  DeltaTR.Telemetry.Abstractions/  数据接口与最新状态
  DeltaTR.Telemetry.ACC/           只读 ACC 适配和演示数据
  DeltaTR.Storage/                 校准持久化、历史开发诊断工具
  DeltaTR.Diagnostics/             历史命令行验证工具（不随产品发布）
tests/DeltaTR.Tests/               协议、质量、校准、语音策略回归
scripts/                          构建、运行、测试、发布
docs/                             使用说明、架构与验证记录
```

旧的 JSONL/CSV 开发工具与回归样本留在开发模块中，仅供诊断；桌面没有入口、采集循环不再调用录制器，发布脚本不再分发探针。已有用户数据不删除。

## 构建与验证

开发需要 .NET 10 SDK；项目本地 SDK 位于 `.tools/dotnet`。首次恢复语音依赖需要连接 NuGet。本地问答离线运行，AI 呼叫连接配置的服务。

```powershell
./scripts/bootstrap.ps1       # 新电脑没有 SDK 时使用
./scripts/install-sensevoice.ps1 # 新默认中文整句识别，下载约 239 MB
./scripts/install-zipformer.ps1  # 源码运行前准备离线模型，正式发布时会自动检查
./scripts/run.ps1 -Demo
./scripts/test.ps1            # 回归，不打开麦克风、不播放声音
./scripts/validate.ps1        # 回归 + 七页实际渲染、窗口控制
./scripts/validate.ps1 -Voice # 额外使用本机中文引擎处理合成音频
./scripts/validate.ps1 -SpeechBenchmark # SenseVoice / Zipformer 合成音频对比
./scripts/publish.ps1
```

构建在 `artifacts/build-tr`，发布在 `artifacts/releases/0.12.0/app`。语音集成检查需要系统中文引擎权限，普通 Windows 用户即可；受限沙箱可能无法使用声音组件。`-Voice` 不采集麦克风、不播放声音，仅输出文本日志和界面截图。
