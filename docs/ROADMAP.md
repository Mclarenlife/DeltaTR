# 当前产品范围与后续验证

用户已将范围收敛为精简 TR：直接语音询问车辆和赛场状况，不需要录制与回放。原始 plan.md 作为研究资料保留，以此范围作为当前实现依据。

| 项目 | 状态 |
|---|---|
| 只读 ACC 共享内存、质量与单位校准 | 已实现；真实 ACC 验证待进行 |
| 三页桌面、一体化系统顶栏 | 已实现并渲染验证 |
| 全局 F8 / 鼠标按住讲话 | 已实现；真实设备与游戏前台手工验证待进行 |

| 录制、回放、文件导出 | 已移出桌面及发布产品范围 |
