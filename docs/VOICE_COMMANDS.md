# 本地语音无线电（0.14.0）

1. 在左侧选择 ACC、Le Mans Ultimate 或 iRacing，连接游戏或启动演示。
2. 在「设置 → 语音与无线电」选择麦克风与识别引擎。首次安装默认 SenseVoice；旧配置保留原来的引擎选择，升级后可手动切换。
3. 点击「测试麦克风」查看实时电平。输入阈值用于判断这一句是否有足够音量，不是识别准确率。
4. 按住绑定的键盘键或方向盘按钮讲话，松开发送。默认 F8，可点击重新绑定后直接按键。
5. 识别结果显示在无线电页面；匹配词库后读取当前游戏遥测，以自定义唤醒词开头时调用已保存的 AI API。
6. 输入与输出设备、音量、阈值、增强及降噪选项通过「保存设置」保存。引擎切换立即保存。

可直接说“帮我看看四条胎各有多热”“左前胎现在多少个 psi”或“左前胎压有没有超过二十六点五 psi”。胎温可指定摄氏度或华氏度。听到“左前胎多少”时，工程师会问胎温还是胎压，同一会话内 20 秒内回答“胎压”会沿用左前轮。iRacing 中，“胎温多少”读取四轮上次测量的中部胎体温度，答复会说明数据来源；明确询问当前胎温时会说明该报告的限制。冷胎设定可直接问“左前冷胎压多少”。普通问法直接读取遥测，自定义唤醒词用于 AI 对话。

Zipformer 无法匹配问句且本机已安装 SenseVoice 时，会用同一段音频复核一次，只接收遥测结果。首次复核需要加载模型。无线电记录显示初次识别和复核信息。

当前游戏词库支持胎温时，“台温多少多少”“胎温多少少”以及一次按键中重复两遍的“胎温多少”可还原为一次查询。轮位和比较数值会保留。不同问题一起说时，请分两次按键。短促的孤立按键声会在提交识别前被过滤。

## 腾讯云工程师音色

在腾讯云开通[实时语音合成](https://cloud.tencent.com/document/product/1073/94308)。在 DeltaTR 选择游戏，进入「设置 → 工程师音色」，勾选腾讯云并填写账号 AppID、SecretId 和 SecretKey，选择云小帅、云小和（超自然大模型）或智云、智靖、智瑜（精品音色）。点「试听音色」使用当前表单试听，点「保存播报设置」应用到工程师回答、赛事提醒和自动化。SecretId 和 SecretKey 使用当前 Windows 用户的凭据保护机制加密保存。

试听及播报时，DeltaTR 发送待合成文本，接收 16 kHz 单声道音频并从所选扬声器流式播放。腾讯云按账号服务规则计量。按住讲话键可以打断播报。如果正式播报在开始播放之前遇到网络或服务错误，会使用可用的 Windows 中文声音播报同一条消息。试听直接报告连接或服务错误，便于检查配置。已开始播放的消息发生中断时不会重复从头播放。

## 识别引擎

- **SenseVoice**：本机中文整句识别，松键后推理，首次加载模型，后续复用。正式发布包自带 int8 模型，两个 CPU 线程，不需要 Python 或云端 ASR。自定义词库在识别后匹配，并复用赛车词同音纠错；不支持本次接入方式下的原生热词加权。
- **Zipformer**：本机中英双语流式识别，按住时解码，松键后提交；支持原有热词提示、词库匹配与唤醒词。
- **Windows**：系统 zh-CN 识别组件，使用命令与听写语法。Windows 置信度滑块只对这一引擎生效。

三种引擎均不因声音大就强行接受一句话。未命中词库、含糊或无效输入会提示重说。SenseVoice 与 Zipformer 不提供这里可直接采用的概率置信度，不显示虚构的百分比。

## 遥测问法与 AI

| 查询 | 示例 |
| --- | --- |
| 胎温、胎压 | 当前轮胎温度多少、胎温、右后胎压多少 |
| 燃油、车速 | 还剩多少油、车速 |
| 排名、圈速 | 排名、上一圈、刚才圈速 |
| 前后差距 | 前车差多少、后车差多少 |
| 天气 | 气温、路温、下雨吗 |
| AI 对话 | 工程师，我应该第几圈进站 |

词库页面可为每款游戏分别编辑问法。普通遥测问题走本地查询；默认唤醒词为“工程师”，可以自定义。AI 对话需要配置地址、模型和密钥，其遥测上下文来自当前驾驶会话。

“台温”可在当前词库能唯一匹配“胎温”时纠正，不进行无条件的单字替换；否定句或相近但不确定的轮位不会强行映射。不同游戏或字段可能没有实时可读数据，不用历史值冒充新读数。

## 音频与生命周期

NAudio 从所选麦克风采集 16 kHz、16 bit、单声道 PCM。音频只保存在内存中，最多按住 15 秒，底层缓存上限 16 秒；松键后的端点静音不再采集麦克风。不提供录制和回放页面。

输入测试与识别使用同一增强、降噪设置。默认关闭两项，可按实际麦克风效果切换。Windows 和 SenseVoice 使用整句归一化后的 WAV；Zipformer 接收采集时的流式样本。现有降噪是轻量滤波，不能承诺消除所有游戏声音或键盘声音。

识别本身不上传音频。只有明确使用唤醒词调用 AI 时，才向已配置服务发送文字与遥测上下文。切换游戏、引擎、禁用讲话或关闭窗口会取消当前请求；迟到结果不得覆盖新会话。SenseVoice 原生推理在当前调用结束后响应取消，模型释放等待推理退出。

缺少模型或系统识别组件时，设置显示原因；缺少中文播报声音时仍可显示文字。源码运行需先执行对应模型安装脚本再构建，完整发布包可直接运行。

[项目对比与合成语音验证](SPEECH_RESEARCH.md)记录了此次测试结果和未解决的带噪输入，不代表真人实测识别率。
