# DeltaTR 界面（0.13.0）

「屏显」顶部新增 KS Pro 方向盘屏幕卡片，可选择 MOZA 基座、刷新设备、打开配套仪表文件夹并手动连接。需要在 Pit House 上传并应用 DeltaTR KS Pro 仪表后退出 Pit House。此实验模式独占基座串口，具体范围见 [KS Pro 说明](MOZA_KS_PRO.md)。桌面屏显调整项仍独立控制电脑悬浮窗。

所有下拉框使用统一深色圆角菜单、选中标记与焦点描边；滑动条使用薄轨道和薄荷色圆形滑块，保留拖动、轨道点击与键盘调节。滚动条使用简约圆角滑块，支持横向和纵向滚动。

「策略组」提供当前游戏的 AI 对话偏好和分析卡片。可选择简短、标准或详细回复，以及稳健、均衡、进取的策略倾向，填写最多 2000 字的自定义偏好。勾选进站、换胎、圈速保持分析控制卡片显示，点击“保存偏好”应用并写入本机设置。恢复默认后也需要保存。普通唤醒词对话与分析按钮使用同一套已保存偏好。

分析按钮使用「设置」中的 AI 地址、模型和密钥。需要有效驾驶遥测或演示数据，结果显示在对应卡片与无线电，标出所依据遥测的时间。采样数据、建议卡片按会话隔离，切换游戏会加载该游戏保存的偏好。近期圈速与每圈油耗只在本次运行内采样，数据不足时由工程师说明缺少的依据。iRacing 的上次测量胎温和冷胎设定会在分析上下文中明确标识。

「自动化」为当前选中的游戏保存规则。新建规则或选择模板，设置触发条件，添加 1–12 个按顺序执行的播报动作，点击“保存自动化”。支持间隔、开赛、完赛、排名升降、黄旗、蓝旗、黄旗解除、处罚、处罚清零、进出站和每圈触发。勾选启用状态后保存可以停用规则，“预览播报文字”使用当前遥测生成结果。每个游戏最多 40 条规则。默认尚未创建规则。

进入「设置 → 赛事主动提醒」，选择要配置的游戏，分别勾选黄旗、本车排名变化和本车处罚。每款游戏默认开启这三项，蓝旗、黄旗解除、进出维修区、每圈和比赛开始/结束可以额外开启，修改后立即保存。驾驶中出现新事件时，工程师会使用设置的输出设备播报，屏显和无线电页也会显示文字。关闭「语音播报工程师回答和赛事提醒」后仍可看文字。按住讲话键时工程师让出无线电，过期或已解除的提醒会丢弃。

左侧顶部选择游戏，每次启动均等待选择。未选择时隐藏工作区并禁用语音、屏显和功能命令。选择后自动连接对应数据源，演示、词库和问答限定于该游戏。左侧导航，右侧内容；48 px 一体化窗口顶栏包含品牌、当前页面、数据源状态及原生最小化/最大化/关闭控制。

- **无线电**是默认页：车手问题、工程师回答、按住讲话按钮、输入音量、停止播报、备用文字输入；右侧显示驾驶会话和问句提示。
- **车辆与赛况**：车速、油量、排名、四轮状态和赛况简报。不可用、未校准或过期字段用破折号，不以正常数值展示。
- **自定义词库**左侧列出可查询的遥测项目，右侧每行编辑一个问法。字段可按中文名称、分组或协议名筛选。保存后，按键讲话和文字查询使用相同的映射。设置页显示所选游戏的赛事数据状态。ACC 的 UDP 广播可单独配置，LMU 和 iRacing 使用原生计时数据，按总排名查询前后车。iRacing 在有效连接后按会话公布的 SDK 变量更新词库。
- **屏显**可预览冰晶助手，调整文字方向及文字、形象、背景各自的不透明度。开启独立置顶窗口后可拖动形象定位。连接后待命时只显示冰晶，断开时气泡提示“未连接”。按住讲话键时冰晶轮廓随输入电平变形。
- **设置**：ACC/演示/断开连接；键盘或方向盘按钮绑定（默认 F8）与开关、自动播报、音量和测试播报；SenseVoice、Windows 或 Zipformer 离线识别引擎、输入和输出设备、输入音量和 Windows 识别置信度、API 地址、模型、密钥、唤醒词和校准配置。字段检查器收起在高级区域，原始数据仍明确显示质量。

没有录制、回放、CSV 或质量报告页面。演示必须由用户选择，不会在 ACC 断线时自动顶替真实数据。左侧演示按钮可随时切换；切换会停止麦克风和播报、取消待返回的语音请求。

`Views` 保存页面，`Themes/Shell.xaml` 保存窗口与通用样式，`Themes/Inputs.xaml` 统一下拉框、滑动条与滚动条；`MainViewModel.cs` 管理数据，`MainViewModel.Voice.cs` 管理语音交互，`Input/PushToTalk.cs` 处理键盘或方向盘按钮的按下与松开。采集与识别实现位于独立 `DeltaTR.Voice` 项目。

集成检查覆盖五页普通/最小尺寸、导航绑定、字段筛选、窗口控制和绑定错误日志；不宣称已人工验证所有 DPI、键盘设备和全屏游戏环境。
